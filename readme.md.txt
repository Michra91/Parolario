# 🟩 Parolario Famiglia

Web App in stile Wordle per 2-3 giocatori (pensata per uso familiare).

## Funzionalità
- Parola del giorno + modalità illimitata
- Tastiera virtuale con feedback colori
- Classifica con punti, vittorie e streak
- Salvataggio persistente su file JSON
- Design mobile-first

## Esecuzione locale
```bash
pip install -r requirements.txt
streamlit run app.py
